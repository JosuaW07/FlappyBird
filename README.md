# React Flappy Bird Clone

Ein interaktiver HTML5‑Canvas-Flappybird-Clone mit Skins, gebaut mit React.

## Features

- Mit Delta Time wird probiert, die Spielgeschwindigkeit immer auf 60 FPS zu halten.
- Durch das Erreichen eines neuen Highscores kann ein seltener Skin freigeschaltet werden.
- Hintergrundmusik kann an- und ausgeschaltet werden.
- Das Spiel kann pausiert werden.
